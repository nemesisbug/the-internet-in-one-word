## The word

**slop**

The whole internet in one word. It used to be a web of pages made by people;
now every feed is flooded with machine-made filler — low-effort, low-signal,
served by the troughful. The word is funny because it is gross and blunt, and
it is true because it is what the internet has become: not a library, not a
town square, a trough. One syllable, instantly readable, and it lands before
you have time to think — then you nod, because you have scrolled through it
all day. It beats the obvious answers ("chaos", "memes", "everything") on
surprise while saying more about the internet as a whole than any of them.

## How it works

`main.py` writes the single word `slop` to `/output/entry.txt`. That is the
entire entry: one word, four letters, no explanation needed.

```sh
python3 main.py
cat /output/entry.txt
# slop
```

Deterministic, no network, no input. Python 3.13.
